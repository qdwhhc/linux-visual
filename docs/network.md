# 联网行为说明

本文档逐条列出 Linux Visual 客户端在运行时的所有对外网络行为，便于用户审查。

## 结论

客户端**不会**向维护者自己的服务器发送任何数据。

没有遥测、没有埋点、没有统计上报、没有后台心跳、没有自动更新请求。

## 全部对外连接

### 1. SSH / SFTP

- 目标：你在“连接账号”中填写的服务器
- 库：`ssh2`
- 用途：执行命令、传输文件、读取系统信息
- 触发：由你主动连接

### 2. MySQL / MariaDB

- 目标：你在“数据库管理”中填写的数据库地址
- 库：`mysql2`
- 用途：查看库表结构、执行 SQL、导入导出
- 触发：由你主动连接
- 说明：不使用该功能时不会发起任何数据库连接

### 3. 对象存储

- 目标：你在“对象存储”中配置的存储地址（腾讯云 COS、阿里云 OSS、华为云 OBS 或兼容 S3 的服务）
- 协议：HTTPS / HTTP（按你填写的 Endpoint）
- 用途：上传、下载、列举、删除对象
- 触发：由你主动操作
- 代码位置：`src/main/main.cjs` 中的对象存储请求函数

### 4. 内置浏览器

- 目标：你在地址栏或书签中访问的网站
- 用途：网页浏览
- 触发：由你主动访问

### 5. 打开官网授权链接

- 目标：官网授权中心页面
- 方式：调用系统默认浏览器打开，不在应用内发送数据
- 触发：仅在“应用授权”页面点击“获取授权”时
- 地址：`src/main/offline-license.cjs` 中的 `PURCHASE_PAGE_URL`

## 不会发生的行为

- 不上传服务器凭据、文件内容或操作记录
- 不上传设备信息用于统计
- 不在后台自动连接任何维护者域名
- 不静默执行自动更新下载

## 本地数据

应用自身数据保存在本机，使用内置 WASM 版 SQLite（`sql.js`）写入：

```text
<用户数据目录>/app-data.sqlite
```

不产生任何跨设备同步。
